# Experiment 13 – MongoDB with Mongoose

## Objective
To connect an Express.js application with MongoDB using Mongoose and perform basic user-management operations.

## Technologies
- Node.js
- Express.js
- MongoDB
- Mongoose
- dotenv

## Features
- MongoDB connection
- Environment variables
- Mongoose schema
- Mongoose model
- User registration
- User login
- Database queries
- Unique username and email
- Automatic creation date

## Configuration

Create a `.env` file:

```env
MONGO_URI=your_mongodb_connection_string
```

Do not commit `.env` to GitHub.

## How to Run

```bash
npm install
node server.js
```

Open:

```text
http://localhost:3000
```
