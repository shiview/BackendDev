# Experiment 1 – HTML5 Web Page and Form Demonstration

## Objective
To create a structured HTML5 webpage demonstrating common HTML elements, forms, tables, lists, multimedia, and input styling.

## Features
- HTML5 document structure
- Header and navigation
- Sections and headings
- Forms and fieldsets
- Input elements
- Tables
- Ordered and unordered lists
- Multimedia elements
- Images and figures
- CSS styling
- Responsive layout

## Main File
```text
index.html
```

## How to Run
Open `index.html` directly in a modern web browser.

## Technologies
- HTML5
- CSS3
