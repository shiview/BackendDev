# Experiment 1 – HTML5 Web Page and Form

## Aim
To create a complete HTML5 webpage demonstrating semantic structure, text formatting, lists, tables, forms, multimedia, interactive HTML elements, and responsive CSS.

## Program Description
This experiment creates a skincare information website named **Skincare Hub**. It is a single-page HTML application with multiple sections connected through navigation links.

The page demonstrates HTML5 features including:

- Semantic page sections
- Header and navigation
- Headings and paragraphs
- Text formatting elements
- Ordered and unordered lists
- Description lists
- Tables
- Forms
- Text, email, date and other input controls
- Radio buttons and checkboxes
- `figure` and `figcaption`
- Images and responsive images
- Audio and video
- `details` and `summary`
- `dialog`
- `address`
- `abbr`, `code`, `kbd`, `mark`, `del`, and `ins`
- CSS transitions and hover effects
- Responsive media queries

## Main File

```text
Experiment1/
└── index.html
```

All HTML and CSS are contained in `index.html`.

## How to Run

No Node.js or Python server is required.

1. Open the `Experiment1` folder.
2. Double-click `index.html`.
3. Open it in Chrome, Edge, Firefox, or another modern browser.

## Page Sections

The navigation includes:

```text
Home
About
Routines
Ingredients
Skin Profile
Media
Interactive
```

These are implemented as sections on the same page.

## Concepts Demonstrated

### Semantic HTML
The page uses elements such as:

```html
<header>
<nav>
<main>
<section>
<footer>
<figure>
<figcaption>
```

### Forms
The page demonstrates different form controls and validation-related CSS.

### Tables
The ingredient comparison section uses table elements such as:

```html
<table>
<thead>
<tbody>
<tr>
<th>
<td>
<caption>
```

### Multimedia
Audio and video elements are included to demonstrate HTML5 multimedia support.

### Responsive Design
CSS media queries adjust the layout for smaller screens.

## Expected Result

A styled **Skincare Hub** webpage opens in the browser with navigation, informational sections, tables, forms, multimedia and interactive HTML elements.
